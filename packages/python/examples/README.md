# Python examples

- [multi-agent-demo](multi-agent-demo/README.md) — recommended first example;
  dependency-free evaluation of a coordinator and four named agents using
  `expose({...})`, `@surface`, structured trajectories, and critical holdouts.
- [langgraph-demo](langgraph-demo/) — realistic SQLite-backed LangGraph agent
  with separate classification and response nodes.
- [`wiretap_demo.py`](wiretap_demo.py) — minimal capture demonstration with no
  API key.

For OpenAI, Anthropic, Fireworks, Ollama, and subscription-backed examples, see
the repository-level [examples index](../../../examples/README.md).
